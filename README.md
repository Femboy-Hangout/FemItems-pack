# FemItems resource pack

Textures and models for the server's FemItems custom items (Weapons Pack, Platinum Set).

`femitems-items.zip` is generated by the FemItems plugin (`plugins/FemItems/resourcepack/femitems-items.zip`)
and sent to players automatically. Do not edit it by hand: change the content packs on the server, run
`/femitems reload`, then replace this file with the newly generated zip and run `/femitems pack`.

The server links to the raw file:
`https://raw.githubusercontent.com/Femboy-Hangout/FemItems-pack/main/femitems-items.zip`

Textures belong to their original authors (Redstone Labs "Weapons Pack - Free Edition", Blossom Studios "Platinum Set").
